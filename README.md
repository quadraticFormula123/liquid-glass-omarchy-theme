# Liquid Glass Omarchy Theme

An Apple liquid-glass inspired Omarchy theme with rounded corners, floating waybar translucency and a modern look. 

## Installation

```bash
omarchy install theme https://github.com/quadraticFormula123/liquid-glass-omarchy-theme && cp ~/.config/omarchy/themes/liquid-glass-omarchy-theme/waybar.jsonc ~/.config/waybar/config.jsonc && omarchy-restart-waybar
```

> **Note**
>
> This theme is still under active development. Things will change, some features are unfinished, and you may occasionally need to re-copy the Waybar configuration after updates until Omarchy supports theme-specific Waybar configs automatically. Things undergoing developement: menu and notification styling and more.
