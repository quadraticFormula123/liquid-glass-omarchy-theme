# Liquid Glass Omarchy Theme

A glass-inspired Omarchy theme with floating UI elements, rounded corners, translucency, and a clean, modern look inspired by Apple's Liquid Glass design.

## Installation

```bash
git clone https://github.com/quadraticFormula123/liquid-glass-omarchy-theme ~/.config/omarchy/themes/liquid-glass-omarchy-theme
```

```bash
cp ~/.config/omarchy/themes/liquid-glass-omarchy-theme/waybar.jsonc ~/.config/waybar/config.jsonc && omarchy-restart-waybar
```

> **Note**
>
> This theme is still under active development. Things will change, some features are unfinished, and you may occasionally need to re-copy the Waybar configuration after updates until Omarchy supports theme-specific Waybar configs automatically.
